# AI Code Generator

An intelligent code-generation tool built with Vue 3 + TypeScript + Vite, specialized in generating HTML5 games. Supports multiple AI models with rich game presets and custom configuration.

[中文](README.md)

## Features

- 🎮 **Game presets** — Snake, 2048, Tetris, Flappy Bird and more
- 🤖 **Multi-model support** — OpenAI GPT, Deepseek, …
- ⚙️ **Flexible config** — per-preset customization
- 🎨 **Theme switching**

## Development

```bash
pnpm install
pnpm dev
```
